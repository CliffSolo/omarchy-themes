# Omarchy Themes

Copies of the 42 extra Omarchy themes I use, so a new PC can install them all from one place (used by `install.sh` in my dotfiles).

Every theme belongs to its original author and is shared under the MIT License. Each theme's own LICENSE file is kept in its folder where the original repo had one. Go to the original repo for updates, issues and credit.

## Install

```bash
git clone --depth 1 https://github.com/CliffSolo/omarchy-themes.git /tmp/omarchy-themes
cp -r /tmp/omarchy-themes/*/ ~/.config/omarchy/themes/
```
